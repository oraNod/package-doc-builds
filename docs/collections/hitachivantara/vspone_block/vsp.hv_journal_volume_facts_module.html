hitachivantara.vspone_block.vsp.hv_journal_volume_facts module – Retrieves information about Journal Volumes from Hitachi VSP storage systems.

Note

This module is part of the hitachivantara.vspone_block collection (version 4.4.2).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install hitachivantara.vspone_block. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: hitachivantara.vspone_block.vsp.hv_journal_volume_facts.

DEPRECATED

Removed in:

version 5.0.0

Why:

Replaced by improved module with consistent naming

Alternative:

hv_journal_facts

Synopsis

  • This module retrieves information about Journal Volumes from Hitachi VSP storage systems.

  • It provides details such as journalId, journalStatus, and other relevant information..

  • Forexamples, go to URL https://github.com/hitachi-vantara/vspone-block-ansible/blob/main/playbooks/vsp_direct/journal_volume_facts.yml

  • It provides details such as journalId, journalStatus, and other relevant information.

  • DEPRECATED - Use hv_journal_facts instead.

  • This module will be removed in a future release.

Requirements

The below requirements are needed on the host that executes this module.

  • python >= 3.9

Examples

- name: Retrieve information about all Journal Volumes
  hitachivantara.vspone_block.vsp.hv_journal_volume_facts:
    storage_system_info:
      serial: "811150"
    connection_info:
      address: storage1.company.com
      username: "admin"
      password: "password"

- name: Retrieve information about a specific Journal Volume
  hitachivantara.vspone_block.vsp.hv_journal_volume_facts:
    storage_system_info:
      serial: "811150"
    connection_info:
      address: storage1.company.com
      username: "admin"
      password: "password"
    spec:
      journal_id: 10
